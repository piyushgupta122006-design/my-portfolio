# Piyush Gupta | Portfolio

> Building high-performance tools for students. Obsessed with Logic, Data & Clean UI.

**🔗 Live:** [my-portfolio-piyushgupta.vercel.app/]([https://my-portfolio-piyushgupta.vercel.app/](https://my-portfolio-piyushgupta.vercel.app/)

A single-page developer portfolio with a dark-tech / cyberpunk aesthetic — neon blue accents, glassmorphism cards, and subtle scroll-reveal animations. Built with HTML, CSS, and vanilla JS — no framework, no build step.

---

## ✨ Features

- **Glassmorphism UI** — frosted `ios-card` components with soft cyan glow on hover
- **Animated role typewriter** — cycles through *BSc CS Student*, *Problem Solver*, *Web Developer*
- **Scroll-reveal animations** — cards fade/slide into view via `IntersectionObserver`
- **One-click email copy** — with toast confirmation, no mailto redirects
- **Ambient background** — floating gradient orbs + subtle grid overlay (disabled on mobile for performance)
- **SEO-ready** — meta description, Open Graph tags, custom favicon
- **Fully responsive** — optimized for mobile, tablet, and desktop

## 🚀 Running Locally

No build tools or dependencies required.

```bash
git clone https://github.com/piyushgupta122006-design/<repo-name>.git
cd <repo-name>
```

Then simply open `index.html` in your browser, or serve it with any static server (e.g. VS Code's Live Server extension).
